# GPT Image 2 プロンプトギャラリー

画像生成ワークフロー向けのローカルプロンプトギャラリーとプロンプトコンパイラーです。構造化されたケース、再利用可能なテンプレート、任意の AI 最適化、ルールベースのローカルコンパイラーをデスクトップアプリにまとめています。

言語：[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

## 機能

- ローカルのプロンプトケースを閲覧し、全文と中国語訳を確認できます。
- API キーなしで、短い要求を構造化された画像・動画プロンプトへコンパイルできます。
- ユーザーが設定した OpenAI 互換エンドポイントによる AI 最適化を任意で利用できます。
- アスペクト比、文字の扱い、人物数、商品の同一性、ネガティブ条件など、明示された制約を保持します。
- ポスター、商品、UI、インフォグラフィック、シーンなどに使えるローカルスタイルライブラリとテンプレートを利用できます。
- Vite の開発モードと Windows Electron デスクトップアプリに対応します。

## ローカル開発

Node.js 22.12.0、または互換性のある `22.x` を使用してください。

```bash
npm ci
npm run verify
npm run electron:dev
```

開発サイトだけを起動する場合：

```bash
npm run dev
```

## テストとパッケージ化

```bash
npm test
npm run test:all
npm run verify
npm run dist:win
```

`verify` は自動テストと本番ビルドを実行します。`dist:win` は検証に成功してから Windows インストーラーを作成します。

## ローカル API 設定

アプリ設定で互換エンドポイント、モデル、API キーを入力すると、AI 最適化スイッチを利用できます。設定がない場合も、ルールベースのローカルコンパイルは使用できます。認証情報はローカルアプリ設定または無視対象の環境ファイルに保存し、リポジトリへコミットしないでください。

## プロジェクト構成

- `src/optimizer/` — プロンプトコンパイラー、テンプレート、最適化 UI、回帰テスト。
- `src/image25/` — ローカルギャラリーとケース表示 UI。
- `data/` と `cases.json` — ローカルケースとスタイルライブラリのデータ。
- `docs/` — ローカルギャラリー、テンプレート、設計記録、利用メモ。
- `agents/skills/` — ローカルスタイルライブラリ Skill と生成済みリファレンス。
- `electron/` — デスクトップアプリのメインプロセスと preload スクリプト。
